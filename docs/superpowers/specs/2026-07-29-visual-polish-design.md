# 个人网站视觉精修设计（方案 A：经典学术风）

日期：2026-07-29
状态：已确认

## 目标

在不改变信息架构、不新增内容板块的前提下，对网站做系统性的视觉与阅读体验精修，使其更接近成熟学术主页的质感。范围覆盖首页与全部文章页。

明确不做：新增内容板块、SEO/Open Graph、KaTeX 数学渲染、外部字体 CDN（用户位于中国大陆，Google Fonts 访问不稳定）。

## 1. 主题与色彩

- 浅色为无条件默认：移除 `main.js` 中跟随 `prefers-color-scheme` 自动进入深色的逻辑；未存储偏好时一律浅色。
- 手动切换仍通过 localStorage 持久化。
- 切换按钮由 ⚙ 改为日/月图标（当前为浅色时显示月亮，深色时显示太阳），`aria-label` 表达「切换主题」。
- 浅色主题微调：正文墨色加深（提高对比度），链接蓝收敛为沉稳的学术蓝。
- 深色主题同步微调，保持两主题下的层级一致。

## 2. 字体与排版层级

- 标题（h1/h2/h3、品牌名、侧栏姓名、文章标题）改用衬线字体栈：
  `Georgia, "Times New Roman", "Songti SC", "Noto Serif SC", serif`
- 正文保持无衬线系统栈（含 `Noto Sans SC` 中文回退）。
- 字重收敛为三级：标题 700、强调 600、正文 400（替换现有大量 800）。
- 标题字号收小一档：h1 约 2.2rem，h2 约 1.5rem，其余按比例调整。

## 3. 首页精修

- 内容列宽收窄至约 72 字符的可读行宽。
- 出版物列表按学术惯例排版：标题常规字重、期刊名斜体突出、作者中 "B. Yin" 加粗、条目间距收紧。
- 侧栏图标从 44px 收小至 36px，链接行距相应收紧。
- Research Interests 左边框卡片保留，间距统一。

## 4. 文章页阅读体验

- 文章正文列宽收窄至约 720px。
- 文章标题使用衬线体。
- hero 图去掉硬编码近黑底色（`#020402`），改中性底 + 细边框。
- 修复 `.article-table-wrap` 中未定义的 `--paper` 变量（改用已定义的主题变量）。
- Citation 框改为浅底卡片样式。
- 「返回 Blog / 返回想法」链接加方向箭头。

## 5. 实现方式

- 模板改动集中在 `scripts/build.js`，样式在 `assets/styles.css`，主题逻辑在 `assets/main.js`。
- 改完运行 `npm run build` 重新生成 `index.html` 与 `posts/*.html`。
- 浏览器验证：明暗两主题、首页与文章页、移动端（860px / 560px 断点）。
- 保留仓库中已有的域名迁移改动（`bojianyin.github.io`）。

## 验收标准

- 首次访问（无 localStorage）一律浅色；切换后刷新保持所选主题。
- 标题呈衬线体，中英文标题均正常渲染。
- 首页与文章页正文行宽明显收窄，无水平滚动。
- 出版物列表中 "B. Yin" 加粗、期刊名斜体。
- 文章页表格背景正常（无 `--paper` 失效问题）。
- 明暗两主题、桌面与移动端布局无破版。
